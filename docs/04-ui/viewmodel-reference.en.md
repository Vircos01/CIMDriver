# ViewModel reference

This document describes the ViewModel layer of CIMDriver. ViewModels form the link between the UI and underlying data or service layers, and model screen-specific state and derived information.

## Scope

The current codebase contains ViewModels for addresses, settings, trip details, trips, vehicles, and work hours, plus separate UI state and chart models. This structure shows that state management is distributed across multiple domains.
