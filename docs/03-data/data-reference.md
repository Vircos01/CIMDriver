# Data-referentie

Dit document beschrijft de data- en repositorylaag van CIMDriver. Deze laag omvat lokale opslag, database-toegang, entiteiten en de repositorylogica waar hogere applicatielagen op steunen.

## Reikwijdte

De data-gerelateerde broncode bevindt zich in `data/local`, `data/local/dao`, `data/local/entity` en `data/repository`. Daarmee zijn zowel opslagstructuren als toegangs- en abstraheringslagen expliciet in de repository aanwezig.
