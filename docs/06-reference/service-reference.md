# Service-referentie

Dit document beschrijft de service- en receiverlaag van CIMDriver. Deze laag vormt de operationele kern van automatische ritregistratie, statusbeheer, herstel, geofencing en systeemreacties.

## Reikwijdte

De servicepackage bevat componenten voor tracking, Bluetooth-events, boot-events, geocoderfunctionaliteit, geofencebeheer, notificatie-acties en statusgerelateerde opslag. Daarmee fungeert deze package als de brug tussen Android-systeemevents en de functionele logica van de applicatie.
