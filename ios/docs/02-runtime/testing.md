# Teststrategie

## Testlagen

- Unit tests voor classificatie, toleranties en rekenregels.
- Integratietests voor repository-, opslag- en frameworkadapters.
- UI-tests voor onboarding, permissies en kernflows.
- Praktijktests voor voertuigdetectie, achtergrondgedrag en batterij-impact.

## iOS-specifieke aandachtspunten

Test op meerdere iPhone-formaten, verschillende toestemmingsscenario's en met echte achtergrondovergangen. Valideer ook CarPlay-gerelateerde flows waar relevant.
