# Test strategy

## Test layers

- Unit tests for classification, tolerances, and calculation rules.
- Integration tests for repository, storage, and framework adapters.
- UI tests for onboarding, permissions, and core flows.
- Practical tests for vehicle detection, background behavior, and battery impact.

## iOS-specific considerations

Test on multiple iPhone sizes, different permission scenarios, and with real background transitions. Also validate CarPlay-related flows where relevant.
