# Release-checklist

- Versienummer en buildnummer verhoogd.
- Info.plist-teksten en capabilities gecontroleerd.
- Privacy manifest en App Store metadata bijgewerkt.
- Kernflows handmatig getest op minimaal één echt toestel.
- Export, notificaties en trackingherstel gevalideerd.
- Bekende beperkingen opgenomen in release notes.
