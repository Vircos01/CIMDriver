# Achtergrondtaken

## Mogelijke mechanismen

- Background App Refresh voor beperkte periodieke verwerking.
- BGTaskScheduler voor geplande achtergrondtaken.
- Significant location changes of region monitoring voor energiezuinige triggers.

## Richtlijnen

Documenteer per taak het doel, de trigger, verwachte looptijd, faalgedrag en energie-impact. Beschrijf ook welke taken niet gegarandeerd op hetzelfde moment als Android uitgevoerd kunnen worden.
