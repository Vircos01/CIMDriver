# Service-referentie

## Doel

Deze referentie documenteert applicatieservices en infrastructuurservices die door meerdere features gebruikt worden.

## Verwachte services

- PermissionCoordinator
- NotificationService
- LocationTrackingService
- BluetoothMonitoringService
- GeocodingService
- ExportService
- DiagnosticsService

## Richtlijn

Per service moet duidelijk zijn welke protocollen worden aangeboden, welke afhankelijkheden bestaan en in welke laag de service thuishoort.
