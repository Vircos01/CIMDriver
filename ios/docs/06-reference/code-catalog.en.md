# Code catalog

## Purpose

The code catalog links the documentation to the actual SwiftUI project structure. This document will become the bridge between conceptual chapters and concrete folders, files, targets, and packages.

## Proposal for cataloging

- `App/` for entry point, container, router, and scene configuration.
- `Features/` for feature-oriented SwiftUI modules.
- `Domain/` for models, use cases, protocols, and services.
- `Infrastructure/` for Apple framework adapters and persistence.
- `Shared/` for design system, components, and utilities.
- `Extensions/` for widget or CarPlay targets.

## Guideline

Expand this page further once the Xcode project structure is final, so that documentation and code reference each other one-to-one.
