# Codecatalogus

## Doel

De codecatalogus koppelt de documentatie aan de feitelijke SwiftUI-projectstructuur. Dit document wordt de brug tussen conceptuele hoofdstukken en concrete mappen, bestanden, targets en packages.

## Voorstel voor catalogisering

- `App/` voor entrypoint, container, router en sceneconfiguratie.
- `Features/` voor featuregerichte SwiftUI-modules.
- `Domain/` voor modellen, use-cases, protocollen en services.
- `Infrastructure/` voor Apple-framework adapters en persistence.
- `Shared/` voor design system, componenten en utilities.
- `Extensions/` voor widget- of CarPlay-targets.

## Richtlijn

Werk deze pagina verder uit zodra de Xcode-projectstructuur definitief is, zodat documentatie en code één op één naar elkaar verwijzen.
