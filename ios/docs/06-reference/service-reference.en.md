# Service reference

## Purpose

This reference documents application services and infrastructure services used by multiple features.

## Expected services

- PermissionCoordinator
- NotificationService
- LocationTrackingService
- BluetoothMonitoringService
- GeocodingService
- ExportService
- DiagnosticsService

## Guideline

For each service, it must be clear which protocols are provided, what dependencies exist, and to which layer the service belongs.
