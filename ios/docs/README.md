# CIMDriver iOS documentatie

Deze map bevat de volledige Nederlandstalige technische en functionele documentatie van de iOS-variant van CIMDriver. De opbouw volgt bewust dezelfde hoofdstukindeling als de Android-documentatie, zodat verschillen in architectuur, platformkeuzes en implementatiedetails eenvoudig naast elkaar gelegd kunnen worden.
