# Glossary

- **CIMDriver** — Car In-route Metrics Driver, the application for trip and hours registration.
- **Trip lifecycle** — The complete state transition of a trip, from detection to classification and storage.
- **Work session** — A workday or work session with start, pause, and end moments.
- **Capability** — An iOS project setting or entitlement that makes system functionality available.
- **Background task** — Processing scheduled or permitted by iOS outside of active foreground interaction.
- **CarPlay scene** — The projection experience for vehicle screens within Apple CarPlay.
- **Repository layer** — Abstraction layer between storage, domain logic, and UI state.
