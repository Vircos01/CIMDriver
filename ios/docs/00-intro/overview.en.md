# Overview

## Product purpose

CIMDriver for iOS focuses on automatic trip and work hours registration with the same functional objective as the Android app: minimize manual administration and maximize local, privacy-friendly processing.

## Core functionality

- Automatic trip detection based on vehicle signals, location, and context.
- Automatic start, pause, and stop of work hours based on known locations and trip status.
- Insight into trips, hours, addresses, and vehicles via a modern mobile interface.
- Export and reporting for administration and expense claims.

## Scope

The iOS variant requires platform-specific choices regarding background processing, permissions, battery consumption, and CarPlay. Therefore, the documentation follows the same chapters as Android, but with iOS-specific technical implementation.
