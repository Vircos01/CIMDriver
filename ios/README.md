# CIMDriver iOS

Dit is de map voor de iOS-versie van CIMDriver. 
Kopieer alle bestanden van je `CIMDriver-iOS` repository (zoals je `.xcodeproj`, `Podfile`, Swift bestanden, etc.) in deze map.

Let op: De documentatie (zoals je `docs/` map) hoeft niet meegekopieerd te worden, die wordt centraal beheerd in de root van de monorepo.
